# Banner artwork

Original Sega Virtua Cop promotional flyer: [1994 Japanese Sega flyer](https://flyers.arcade-museum.com/arcades/show/1244). Original game artwork and trademarks belong to Sega.

The right panel preserves the complete original-art section selected in the owner’s reference: its logo, blue backdrop, both officers and weapons remain together. No character cutouts or replacement scene were used. The panel keeps its original proportions. The overall 2172 × 724 header uses the same white title, red VR badge, platform line, metadata pill and accents as the other VR4ALL banners. No AI-generated artwork was added.
